# CareerForge AI

> AI-powered mock interview platform designed to help students and job seekers practice interviews, improve communication, and become job-ready.

## 🚀 Overview

CareerForge AI is a full-stack AI mock interview platform that provides an interactive interview experience based on the user's selected role and difficulty level.

The platform uses AI to generate interview questions, conduct conversational interviews, evaluate answers, and provide personalized feedback.

## ✨ Key Features

- 🔐 User authentication and protected routes
- 🎯 Role-based mock interviews
- 📊 Multiple difficulty levels
- 🤖 AI-generated interview questions
- 🎙️ Voice-based interview answers
- 🗣️ Speech-to-text integration
- 🔊 AI-generated voice responses
- 💬 Conversational follow-up questions
- 💻 Live coding interview environment
- 🧠 AI-powered code evaluation
- 📄 Resume-based interview preparation
- 📈 Interview performance analysis
- 📚 Interview history and previous results
- 📊 Personalized performance dashboard
